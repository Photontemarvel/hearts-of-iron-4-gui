## 🧩 About

**Hearts of Iron 4 GUI** is a comprehensive overlay and menu for Hearts of Iron 4 featuring real-time resource tracking, division template editing, production queue management, political power monitoring, and research queue optimization.

Based on popular tools like **HOI4 Overlay**, **Division Designer**, and **Production Manager**.

### 🎮 Core Overlay
- Real-time resource overlay — monitor fuel, supplies, and manpower
- Division template editor — customize and save division designs
- Production queue manager — add, remove, and prioritize production
- Political power tracker — keep an eye on PP generation
- Research queue optimizer — queue technologies efficiently

### 🎨 GUI & Interface
- Customizable HUD — move and resize overlay elements
- Dark mode — reduce eye strain during long sessions
- Hotkey support — bind actions to keys
- Multi-monitor support — place overlay on any screen
- Localization — supports multiple languages

### 🏋️ Utility & Automation
- Auto-save templates — never lose your division designs
- Quick build presets — one-click construction queues
- Alert system — notifications for low resources
- Export/import configs — share setups with friends
- Safe mode — restrict risky features
